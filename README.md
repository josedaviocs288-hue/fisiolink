# FisioLink

Protótipo funcional de uma startup de fisioterapia e prevenção, feito em HTML, CSS e JavaScript puro.

## Recursos demonstrativos
- Cadastro/login de paciente, profissional e clínica (LocalStorage)
- Biblioteca de exercícios com filtros e passo a passo
- Registro de sessões, dor autorrelatada, tempo e histórico
- Acompanhamento de meta semanal
- Busca de profissionais e solicitação de atendimento
- Botão de localização do navegador
- Conteúdos educativos de prevenção
- Acessibilidade com aumento de texto
- Layout responsivo

> O FisioLink é um protótipo e não realiza diagnósticos. Exercícios terapêuticos devem seguir orientação profissional.

## GitHub Pages
